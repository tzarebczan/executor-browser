Executor

Lab

Connect over Tailscale with a personal API key. No companion app required.

In Executor → Settings → API keys (or your account menu) → create a personal key → paste here. Stored only in this browser profile.

Optional · browser automation off

Connect above does not need this. API key is enough for pairing, tabs, and preview. Automation is only if remote agents should drive this Chrome.

Can Executor include the companion? Not really — Executor runs on the server (lab-agents). Browser control must run on your PC next to Chrome. Today that is a small local process (PowerShell + Node MCP), not something the server can install into the extension alone.

Allow remote debugging

Open chrome://inspect/#remote-debugging → Allow (once per Chrome profile).

2
Start the companion on this PC

From the tbd repo (lab scripts). Leaves a process on 127.0.0.1:9230 (MCP). Not packaged as an .exe yet. 

node infra/host/chrome-agent/start-companion.mjs
